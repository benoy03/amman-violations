# نظام إدارة كشف تعديل مخالفات الكاميرات — أمانة عمّان الكبرى
### مديرية الرقابة الآلية والتحكم — قسم المخالفات (المملكة الأردنية الهاشمية)
### Full-Stack Enterprise Web Application (RTL - Arabic)

نظام ويب متكامل واحترافي مصمم خصيصاً لـ **أمانة عمّان الكبرى (مديرية الرقابة الآلية والتحكم — قسم المخالفات)** لإدارة وتدقيق وتعديل مخالفات كاميرات الرقابة الآلية بدقة وموثوقية عالية، مع دعم تنسيق لوحات المركبات الأردنية، والعمل الجماعي المتزامن لعدة موظفين عبر الشبكة المحلية أو السحابية.

## 1. المميزات الرئيسية للنظام

1. **شاشة إدخال وترحيل تفاعلية (15 حقلاً مرتبة بدقة)**:
   - تحقق فوري لحظي (**Live Validation**) من عدم تكرار رقم المخالفة قبل الحفظ.
   - تعبئة تلقائية لاسم اليوم بالعربية فور اختيار تاريخ الإدخال.
   - تعبئة تلقائية فورية لأسماء الموظفين (المستخرج، المدقق، المعدل، المبلغ) للقراءة فقط بمجرد اختيار الرقم.
   - قائمة منسدلة بأنواع الأخطاء الشائعة مع حقل نص حر فوري عند اختيار "أخرى".
   - ترحيل فوري وحفظ مع تنبيهات ملونة وتفريغ تلقائي للنموذج.

2. **سجل المخالفات الكامل (All Violations)**:
   - جدول متجاوب يعرض جميع السجلات مع فرز تصاعدي وتنازلي بالنقر على العناوين.
   - بحث شامل في كل الأعمدة (رقم المخالفة، رقم اللوحة الخطأ/الصحيح، أسماء الموظفين، طبيعة الخطأ).
   - فلترة حسب الفترة الزمنية (من تاريخ - إلى تاريخ) ونوع الخطأ.
   - ترقيم الصفحات (Pagination) وتصدير فوري للبيانات بصيغة CSV / Excel.

3. **شيتات الأدوار التخصصية (المستخرجين، المدققين، المعدلين، المبلغين)**:
   - صفحات مخصصة لكل دور وظيفي.
   - إمكانية التصفية بـ **كشف فردي لموظف محدد** وعرض المخالفات الخاصة به فقط مع ملخص إحصائي لأبرز أخطائه.

4. **التقارير والإحصائيات والرسوم البيانية**:
   - فلتر زمني ذكي: (يومي، أسبوعي، شهري، ربع سنوي، نصف سنوي، سنوي، مدى مخصص).
   - رسم بياني تفاعلي (**Recharts**) يقارن إجمالي العمليات بين الأدوار الأربعة لنفس الفترة.
   - جداول تجميعية تحليلية (Group By + Count + Percentage) لكل دور.

5. **إدارة بيانات الموظفين (للمدير فقط)**:
   - 4 تبويبات لإدارة (المستخرجين، المدققين، المعدلين، المبلغين).
   - إضافة سريعة وتحديث لحظي يظهر فوراً في القوائم المنسدلة بدون إعادة تحميل.
   - حذف آمن (**Soft Delete**) مع فحص تلقائي لعدد المخالفات المسجلة باسم الموظف وعرض نافذة تحذير قبل الحذف.

6. **الطباعة الرسمية وتصدير PDF**:
   - دعم كامل للطباعة التلقائية عبر المتصفح بتنسيق `@media print` المخصص: إخفاء عناصر التحكم والأزرار، وتوليد ترويسة رسمية للمملكة العربية السعودية ومكتب الرقابة الآلية وتاريخ ورقم الصفحة.

7. **الأمان والمصادقة**:
   - مصادقة عبر JWT مع تشفير كلمات المرور بـ bcrypt.
   - صلاحيات واضحة: مدير النظام (Admin) وموظف عادي (User).
   - حماية كاملة من ثغرات الحقن (SQL Injection) عبر استعلامات مُعلمة بالكامل (Parameterized Queries).

## 4. خطوات التثبيت والتشغيل خطوة بخطوة

### الخطوة 1: تثبيت حزم الاعتمادية (Dependencies)
من المجلد الرئيسي للمشروع (`c:\Users\nourb\OneDrive\Desktop\AML`):

```bash
npm run install:all
```
*(أو ادخل مجلد `server` واكتب `npm install`، ثم مجلد `client` واكتب `npm install`)*

---

### الخطوة 2: تهيئة قاعدة البيانات بالبيانات الأولية (Seed Data)
لتوليد المستخدمين وحساب المدير وقوائم الموظفين وعينات مخالفات جاهزة:

```bash
npm run seed
```

---

### الخطوة 3: تشغيل النظام في بيئة التطوير (Development Mode)
لتشغيل الخادم والواجهة معاً بأمر واحد:

```bash
npm run dev
```

- **رابط واجهة الويب**: `http://localhost:3000`
- **رابط خادم الـ API**: `http://localhost:5000`

*(يمكن أيضاً تشغيل الخادم منفرداً عبر `npm run dev:server` والواجهة عبر `npm run dev:client`)*

---

### الخطوة 4: بناء وتشغيل بيئة الإنتاج (Production Mode)
إذا أردت تقديم الواجهة مباشرة من خلال خادم Express:

```bash
npm run build
npm start
```
ثم افتح مباشرة: `http://localhost:5000`

## 6. وثائق واجهة برمجة التطبيقات (API Reference)

### المصادقة:
- `POST /api/auth/login` — تسجيل الدخول والحصول على JWT.
- `GET /api/auth/me` — جلب بيانات المستخدم المسجل.

### المخالفات:
- `GET /api/violations/check-number/:num` — التحقق اللحظي من توفر رقم المخالفة.
- `POST /api/violations` — ترحيل وتسجيل مخالفة جديدة.
- `GET /api/violations` — جلب سجل المخالفات مع البحث والفلترة والفرز والصفحات.
- `GET /api/violations/by-role/:role` — جلب سجلات دور معين (مستخرج، مدقق، معدل، مبلغ) أو كشف فردي لموظف محدد (`?employeeNumber=101`).
- `GET /api/violations/:id` — تفاصيل مخالفة واحدة.

### الموظفون:
- `GET /api/employees/:role` — جلب الموظفين النشطين لتعبئة القوائم المنسدلة.
- `GET /api/employees/:role/all-stats` — (للمدير) جلب الموظفين مع عدد المخالفات المرتبطة بكل منهم.
- `GET /api/employees/:role/check/:number` — (للمدير) فحص عدد مخالفات الموظف قبل الحذف.
- `POST /api/employees/:role` — (للمدير) إضافة موظف جديد.
- `DELETE /api/employees/:role/:number` — (للمدير) حذف موظف حذفاً آمناً (Soft Delete).

### التقارير والإحصائيات:
- `GET /api/reports/statistics?period=month` — جلب إحصائيات الفترة، الجداول التجميعية، وبيانات الرسم البياني.
  - الفترات المدعومة: `day`, `week`, `month`, `quarter`, `half`, `year`, `custom` (مع `startDate` و `endDate`).
